 🎯 Task Summary

Task 1: Web Fundamentals
Objective: Understand how web applications work and HTTP communication.

Rooms Completed:
- TryHackMe: Web Application Basics
- TryHackMe: HTTP in Detail

Skills Gained:
- HTTP/HTTPS protocols
- HTTP methods and status codes
- Headers, cookies, and sessions
- Web application architecture
- Browser Developer Tools

Evidence: Room completions, DevTools screenshots, Network tab, headers, cookies.

---

Task 2: Reconnaissance & Enumeration
Objective: Map an application's attack surface.

Rooms Completed:
- TryHackMe: Passive Recon
- TryHackMe: Active Recon
- TryHackMe: Content Discovery

Skills Gained:
- WHOIS and DNS lookups
- Subdomain discovery
- Directory brute forcing
- Technology identification
- Port scanning with Nmap

Tools Used: WHOIS, Nslookup, Nmap, Gobuster, Browser DevTools.

---

Task 3: Burp Suite
**Objective:** Intercept, analyze, and modify web traffic.

Room Completed:
- TryHackMe: Burp Suite Repeater

Skills Gained:
- Burp Proxy and interception
- HTTP History analysis
- Repeater for manual testing
- Intruder for fuzzing
- Request/Response manipulation

Tools Used: Burp Suite Community Edition.

---

Task 4: Common Web Vulnerabilities
Objective: Identify and test common web vulnerabilities.

Labs Completed:
- PortSwigger: SQL Injection
- PortSwigger: XSS
- PortSwigger: Authentication (Username Enumeration)
- TryHackMe: IDOR
- PortSwigger: Path Traversal

Skills Gained:
- SQL Injection exploitation
- XSS payload crafting
- Authentication bypass
- IDOR identification
- Path Traversal exploitation
- Vulnerability remediation

Tools Used: PortSwigger Academy, TryHackMe, Burp Suite.

 📚 Key Learnings

1. HTTP Fundamentals - Understanding HTTP is the foundation of web security
2. Reconnaissance - Information gathering is critical before testing
3. Burp Suite - Essential tool for intercepting and modifying traffic
4. Vulnerability Testing - Every vulnerability has a root cause and fix
5. Documentation - Clear evidence and reports are as important as exploitation
6. Security Mindset - Always think about "why" a vulnerability exists
